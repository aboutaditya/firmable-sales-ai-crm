# Plan — AI Layer (Qualification, Summary, Outreach)

Component: LLM provider abstraction, deterministic pre-qualification, caching, tracing, and cost accounting. The LLM adds interpretation and natural language — never new evidence.

Source of truth files:
- `sales_intelligence/ai/provider.py`
- `sales_intelligence/ai/service.py`
- `sales_intelligence/ai/content_service.py`
- `sales_intelligence/ai/repository.py`

- `sales_intelligence/ai/tracing.py`
- `sales_intelligence/prompts/*`

## Provider abstraction

`LLMProvider` protocol (`model`, `qualify(company, prompt)`, `generate(company, prompt)`).

`OpenAICompatibleProvider` implements it against any OpenAI-compatible `/chat/completions` endpoint (OpenRouter by default):

- `qualify` requests JSON (`ai_score`, `priority`, `confidence`, `reasoning`), validates with Pydantic, and retries once with a corrective follow-up when the model returns prose instead of JSON.
- `generate` returns raw content for summary/outreach.
- Retries (default `max_retries=2`) with exponential backoff on 408/429/5xx, timeouts, and network errors.
- Tokens from `usage` (`prompt_tokens`/`input_tokens`, `completion_tokens`/`output_tokens`); cost from `LLM_INPUT_COST_PER_1K` / `LLM_OUTPUT_COST_PER_1K`.
- Optional `HTTP-Referer` / `X-OpenRouter-Title` attribution headers.

Prompts substitute `{{company_profile}}` with the JSON profile. Prompt files:

- `prompts/account_scoring/v1.txt` (wired) / `v2.txt` (on disk; refinement for sparse/attribution-uncertain profiles and explicit "never claim a breach or intent").
- `prompts/company_summary/v1.txt`, `prompts/outreach/v1.txt`.

## Pre-qualification and caching

Both services reject companies below the deterministic threshold (`AI_MIN_SCORE` / `min_deterministic_score`) before any LLM call, and return 422 via the controller. Caching is database-backed:

- Assessments: `SqlAlchemyAssessmentRepository.get_latest(company_id, prompt_version)`; a hit returns the stored result with `cached=True` and does **not** call the model.
- Content: `SqlAlchemyAIOutputRepository` keyed on `(company_id, feature, prompt_version)`.

Cache keys always include `prompt_version`, so a prompt change invalidates cached results; there is no TTL.

## Tracing

Every LLM attempt (success or failure) records one event with `feature`, `model`, `prompt_version`, `request`, `response`, `latency_ms`, `input_tokens`, `output_tokens`, `cost_usd`, `decision`, `status`, `error`.

`TraceSink` backends, selected by `LLM_TRACE_BACKEND`:
- `jsonl` — appends to `LLM_TRACE_PATH` (default `data/traces/llm_calls.jsonl`).
- `storage` — uploads one object per call to the `llm-traces` bucket at `traces/<prompt>/<year>/<month>/<day>/<timestamp>-<trace_id>.json` (concurrency-safe on serverless).
- `both` — JSONL mirror + durable object storage (recommended in production).
- Unset/unsupported with missing Supabase env → `NullTraceSink`.

Traces are the input to the generated-output eval ([`10-evals.md`](10-evals.md)) and the cost model below.

## Rate limiting

Per-process sliding-window limiter (`ai_rate_limit_per_minute`, default 30) applied to all three AI routes; 429 on limit.

## Model tiering and cost

| Step | Tier | Notes |
| --- | --- | --- |
| Exposure scoring | none (rules) | deterministic, $0 |
| Qualification | cheapest model passing the eval gate | high volume, binary-ish |
| Summary | same cheap tier | on demand |
| Outreach | stronger tier | customer-facing, low volume |
| Evals | paid mid-tier | measurement must not run on the free router |

```text
cost per call = input_tokens/1000 * input_price_per_1k
             + output_tokens/1000 * output_price_per_1k
```

Measured on `openrouter/free` (2026-09-12, 25-case eval): mean/median input 275/190 tokens, output 1,178/1,063 tokens, latency 18.6s/9.7s. The verbose free router is an upper bound; capping `max_tokens` or using a constrained classifier cuts per-call cost 5–10x.

Production ceiling: project vs a monthly budget (`$50` QA / `$500` prod); when exceeded, the app serves deterministic scores only. That is a valid product state because deterministic reads work without the LLM.
